# References

The public repository contains citation entries and source links. Supplied paper PDFs and extracted paper figures remain in the local reading archive; they are not redistributed here.

| Source | Relevance | BibTeX key |
|---|---|---|
| [Chen et al., *Stochastic Path Sampler For Lattice Field Theory*](https://arxiv.org/abs/2606.13790) | Foundation for data-free path sampling and trajectory-level MH; the supplied version is a preprint, with primary experiments on scalar field theory | `Chen2026SPS` |
| [Wang et al., *Continuous-Mixture Autoregressive Networks Learning the Kosterlitz-Thouless Transition*](https://doi.org/10.1088/0256-307X/39/12/120502) | Related generative XY sampling and physical diagnostics | `Wang2022CAN` |
| [Wolff, *Collective Monte Carlo Updating for Spin Systems*](https://doi.org/10.1103/PhysRevLett.62.361) | Cluster sampler used for reference validation | `Wolff1989Cluster` |
| [Kosterlitz, *Topological Defects and Phase Transitions*](https://www.nobelprize.org/uploads/2018/06/kosterlitz-lecture.pdf) | Vortices and BKT background; a retrospective Nobel lecture rather than the original research article | `Kosterlitz2016Nobel` |
| [Lee and Wang, *Efficient Identification of Critical Regions via Flow Matching-Based Monte Carlo Initialization*](https://arxiv.org/abs/2508.15318) | Related supervised FM initialization, distinct from the present data-free path-space MH study | `Lee2026FMInitialization` |

Core entries are in [references.bib](references.bib). Additional method candidates, including FM initialization, are in [methods_candidates.bib](methods_candidates.bib). Notes record versions checked during the project; inclusion is not a claim to have reproduced every cited method.

See [Method](../docs/public/method.md), [Results](../docs/public/results.md), and [Historical baseline](../docs/public/legacy.md) for implementation and evidence boundaries.
